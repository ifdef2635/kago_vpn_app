# KaGo VPN — состояние релиза

**Статус: релиз 2.1.0** (Android, Windows, macOS). Android — один APK для arm64 (~30 МБ), подписанный постоянным ключом владельца (секреты `KAGO_ANDROID_*`): следующие версии ставятся поверх как обновление. Windows — установщик Inno Setup с постоянным AppId, который тоже обновляет приложение поверх. Каждое некрупное обновление повышает версию на 0.0.1 (правило в CLAUDE.md).

_Обновлено: 2026-10-09 (версия 2.1.0)._ Строка «Платформы: …» в первом разделе задаёт, каким системам приложение предложит обновление (без неё — всем). Первый раздел файла (до «Для разработчиков») публикуется как «Что нового» релиза и показывается в диалоге обновления — писать его для пользователей. Файл обновляется при каждом наборе изменений; новые изменения — сверху.

## 2026-10-09 — версия 2.1.0 (2.1.0+20100)

Платформы: Android, Windows, macOS

Сделано:
- Вкладка «Серверы» как в FlClashX: каждая группа (VPN, YouTube, ИИ…) — карточка с выбранным сервером, раскрывается по нажатию; серверы — компактные карточки в две колонки, выбранный отмечен галочкой. Задержку можно проверить у всей группы (значок в заголовке) или у одного сервера (нажмите на задержку или на молнию). Потяните список вниз, чтобы обновить.
- Режим как в FlClashX — кнопка в заголовке «Серверов»: «По правилам» (как раньше: правила подписки) или «Глобальный» (весь трафик через сервер, выбранный в группе GLOBAL; в этом режиме список показывает только её). Выбор запоминается. В бесплатном режиме Telegram всегда работают правила.
- В заголовке «Серверов», как в FlClashX: проверка задержки всех серверов, «Свернуть все / Развернуть все», поиск по названию сервера и меню «⋮» с сортировкой и обновлением.
- «Соединения» убраны из нижнего меню: теперь они в «Настройки → Инструменты», рядом с логами Mihomo. В нижнем меню четыре вкладки: Главная, Серверы, Кабинет, Настройки.
- Уведомления внизу экрана убраны: приложение больше не пишет «VPN подключён», «Подписка обновлена», «Скопировано» и т. п. Остались только критические ошибки (не удалось подключиться, не работает бесплатный Telegram, не удалось обновить подписку, войти или выполнить действие в кабинете) — с кнопкой «Поддержка»: текст ошибки, который можно скопировать, и чат поддержки KAGO.
- Ошибки в формах — прямо в форме: неверный email или пароль — под полями входа, неверный промокод — под полем промокода, неверный код из письма или текущий пароль — в окне, которое не закрывается, пока не получится.
- Обновление подписки на главной показывает индикатор на кнопке «Обновить». Смена режима «Весь трафик через VPN» на ПК при включённом VPN переподключает его сама (раньше просила переподключиться).
- Иконки групп из подписки (VPN, YouTube, ИИ, Самый быстрый), как в FlClashX. Задержка серверов группы «Самый быстрый» проверяется по её собственному адресу из подписки.
- Android: приложения, которые подписка KAGO просит пускать мимо VPN (банки, Госуслуги, маркетплейсы — около 500), теперь действительно идут напрямую, как в FlClashX. Раньше KaGo этот список игнорировал. Ваш выбор в «Приложения и VPN» добавляется к нему; там же видно, какие установленные приложения идут напрямую по подписке.
- Подписка обновляется сама: так часто, как просит сервер KAGO (сейчас раз в 6 часов), без сервера — раз в сутки. Новые серверы и правила применяются при следующем подключении.
- Кнопка «Поддержка» ведёт туда, куда указывает подписка (страница помощи usekago.net), а без подписки — в Telegram @KaGoHelp.
- В «Кабинете» больше нет второй кнопки подключения: VPN включается одной кнопкой на главной. Если подписки аккаунта на этом устройстве ещё нет, в «Кабинете» есть кнопка «Добавить на это устройство» — она добавляет подписку и открывает главную (или переключает уже включённый VPN на подписку).
- Служебные группы подписки (скрытые и GLOBAL) больше не показываются в списке серверов.
- У автоматических групп («Самый быстрый», «Авто») видно, какой сервер они используют сейчас; при попытке выбрать в них сервер вручную приложение объясняет, что сервер выбирается автоматически.

## 2026-10-08 — версия 2.0.5 (2.0.5+20005)

Платформы: Android, Windows, macOS

Сделано:
- Windows: KaGo VPN живёт в трее. Крестик окна прячет приложение, VPN продолжает работать; открыть — щелчок по значку в трее, полностью выйти — правой кнопкой по значку → «Выход» (VPN при этом отключается, интернет возвращается как был). Повторный запуск ярлыка открывает уже работающее окно, а не вторую копию.
- macOS: после обновления приложение больше не спрашивает пароль по 5–7 раз. При установке 2.0.5 macOS спросит его последний раз (до трёх раз, чтобы перенести вход, подписку и id устройства — нажмите «Разрешить»), дальше — не больше одного раза и только для режима «Весь трафик через VPN», если в обновлении изменилось ядро.
- «Забыли пароль?» больше не советует регистрироваться с той же почтой (сайт этого не позволяет): окно предлагает войти через Telegram или написать в поддержку.
- Светлая тема стала контрастнее: фон и рамки карточек темнее, карточки не сливаются с фоном.
- Windows и macOS: повторное нажатие кнопки питания во время подключения больше не запускает второе ядро, а системный прокси не остаётся включённым без VPN — кнопка ждёт окончания операции.
- После выхода из аккаунта подписка больше не может вернуться из-за фонового обновления счётчиков трафика.
- «Подключить это устройство» при включённом VPN (например, в бесплатном режиме Telegram) переключает VPN на подписку, а не выключает его. После перевыпуска ключа VPN переподключается с новым ключом.
- Неверный пароль при входе показывается как «Неверный email или пароль», а не «Сессия истекла».
- Если подписку не удалось добавить при входе (например, достигнут лимит устройств), приложение говорит об этом, а не пишет «Подписка добавлена».
- Android: метки «Бесплатный доступ к Telegram» и «Анонимный режим» больше не теряются, если приложение закрыли из списка недавних или VPN включили с плитки.
- Бесплатный доступ к Telegram: понятная причина, если сервер KAGO недоступен («сервер KAGO ответил 404…», «нет связи с usekago.net…»), вместо технической ошибки; серверы-заглушки панели и повторяющиеся имена серверов больше не ломают подключение.

Для разработчиков:
- Версия 2.0.4 не выпускалась: её изменения вошли в 2.0.5.

### Состояния при выключенном ядре
- **Вкладка «Серверы»** показывает серверы и группы сохранённого профиля (протокол, вложенные группы, `include-all`/`filter`) вместо ошибки контроллера. Выбранный узел без ядра неизвестен, поэтому не подсвечивается; выбор узла и проверка задержки доступны после подключения.
- **Вкладка «Соединения»** показывает «нет активных соединений» и не опрашивает контроллер.
- **Карточка «Ваш сервер»** показывает группу и число серверов вместо ошибки.
- **Исправление сборки:** `const`-карточка с runtime-значением в `connections_screen.dart`.

### Исправления по аудиту
- **Интерфейс оставался «подключён» после падения ядра** — теперь менеджер процесса сообщает о неожиданном выходе, и интерфейс переключается в «отключено».
- **Закрытие окна могло оставить `mihomo.exe` запущенным** с включённым прокси — теперь ядро останавливается при выходе (лимит 6 с). Ядро, «осиротевшее» после жёсткого падения, при следующем запуске ещё не обнаруживается (см. ниже).
- **Враждебный YAML подписки мог открыть прокси в локальную сеть** — конфиг принудительно получает `allow-lan: false`, `bind-address: 127.0.0.1`, из него удаляются `listeners`, `tunnels`, `authentication`, `external-ui*`, `external-controller-tls/unix/pipe/cors`, `tls` (и, с 2026-10-05, `tuic-server`, `ss-config`, `vmess-config`).
- **Кнопка обновления сообщала об успехе при недоступном GitHub** — теперь говорит, что проверка не удалась и почему.

### Новые функции
- **Карточка IP на главной:** публичный IP, страна/город, провайдер, скрыть/показать, обновить. Сервисы: `ipwho.is` → `api.ip.sb` → `api.ipify.org`. На Windows при работающем ядре запрос идёт через локальный прокси, чтобы показать адрес VPN. Обновляется при включении/выключении VPN, смене узла и раз в 3 минуты. Эти сервисы видят запрос — **указать в политике конфиденциальности**.
- **Автообновление счётчиков подписки** из заголовка `subscription-userinfo`: при запуске, при включении/выключении VPN, раз в минуту при подключении и раз в 5 минут без него.
- **Настройки в стиле FlClashX:** сгруппированные карточки; адрес контроллера и путь к ядру (Linux/macOS) — в диалогах; логи в диалоге с копированием.
- **Windows: проверка SHA-256 расширена** — digest берётся со страницы релиза (если API недоступен), SHA-256 установленного `mihomo.exe` перепроверяется перед запуском; изменённый файл скачивается заново. Старые версии ядра удаляются.
- **Плавность:** Android запрашивает максимальную частоту экрана; переключение вкладок анимировано; главная не перерисовывается каждую секунду; опрос соединений идёт только на видимой вкладке.

### Ранее в этой серии
- **Ядро Windows** ставится в `%APPDATA%\KaGo\core\<версия>\mihomo.exe` и скачивается автоматически при запуске. Если `api.github.com` недоступен и ядра нет, закреплённый ZIP `v1.19.32` скачивается напрямую с `github.com`. Поле «Путь к Mihomo» на Windows убрано.
- **Понятные ошибки вместо `DioException`:** `MihomoCoreNetworkException` объясняет недоступность GitHub; при неудачном запуске показываются последние строки лога ядра.
- **Вкладка «Серверы» в стиле FlClashX:** группы в порядке конфига (GLOBAL последней), карточки узлов с протоколом и задержкой, проверка задержки группы, сортировка; карточка «Ваш сервер» ведёт на эту вкладку.
- **Имена из ссылок** декодируются из `%`-кодировки (флаги, кириллица).
- **Живой трафик** на главной из `/connections`; список соединений обновляется сам.
- **Secret контроллера** создаётся автоматически и хранится в защищённом хранилище; поле Secret убрано.

## Обязательно до публичного релиза

1. **Подпись Android.** Добавить в секреты репозитория ключ владельца (`KAGO_ANDROID_KEYSTORE_BASE64`, `KAGO_ANDROID_KEYSTORE_PASSWORD`, `KAGO_ANDROID_KEY_ALIAS`, `KAGO_ANDROID_KEY_PASSWORD`) или подписывать локально. Ключ, созданный агентом, для постоянной подписи приложения не использовать.
2. **Тесты Android на устройстве:** разрешение/отзыв VPN, переподключение, TUN, `protect()`, трафик по протоколам, DNS/IPv6, очистка при отключении, утечки; вход в кабинет на реальном сервере usekago.net.
3. **Сборка и проверка Windows** на Windows/MSVC: `tool/build_windows_release.ps1`, Visual Studio 2022 с «Desktop development with C++». Проверить автоустановку ядра в `%APPDATA%\KaGo\core` (в том числе при заблокированном `api.github.com`), восстановление прокси после отключения, падения ядра, выхода и перезагрузки. Сертификата подписи и установщика нет.
4. **Обнаружение «осиротевшего» ядра (Windows):** сохранять PID ядра и при следующем запуске останавливать оставшийся `mihomo.exe` (сверив имя образа). Скрывать ссылки/токены подписки в логах перед копированием.
5. **Решить, достаточно ли режима системного прокси на Windows.** Полный VPN требует Wintun, повышенных прав/службы и тестов маршрутов/DNS/утечек.
6. **Канал обновлений Android.** Ядро `.so` поставляется внутри подписанного APK/AAB; новое ядро выходит только с новой версией приложения через Play или другой доверенный канал.
7. **Юридическое и продуктовое:** Mihomo — GPL-3.0; проверить совместимость с лицензией приложения и уведомления об исходном коде; политика конфиденциальности (запросы IP, опрос подписки, API кабинета), условия, поддержка, страница в магазине, резервная копия ключа, сертификат подписи Windows.
8. **Протоколы:** поддерживаются Clash/Mihomo YAML, YAML в base64 и VLESS/VMess/Trojan/SS/Hysteria2/TUIC. SSR и закрытые форматы провайдеров — нет. Перед выпуском добавить тесты на реальных подписках.

## Команды сборки

Android в GitHub Actions: push в ветку `claude/**`, `feat/**`, `fix/**` или тег `v*` — артефакты в разделе **Artifacts** запуска (универсальный APK, APK для arm64, `SHA256SUMS.txt`).

Windows (PowerShell, только на Windows):

```powershell
.\tool\build_windows_release.ps1
```

Android (PowerShell на Windows с Android SDK/NDK и Go):

```powershell
.\tool\build_android_release.ps1
```

Android (Linux/macOS/WSL):

```bash
export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
./tool/build_android_release.sh
```

Сборка без локальных переменных подписи не подписана — не распространяйте её как релиз. Подробнее: [README.md](README.md) и [native/android/README.md](native/android/README.md).
