# Twemoji Country Flags

`TwemojiCountryFlags.ttf` — шрифт только с флагами стран (из пакета
[country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill) 0.1.10,
переведён из WOFF2 в TTF без изменений). Используется на Windows, где системные
шрифты не рисуют эмодзи-флаги.

Рисунки флагов — [Twemoji](https://github.com/twitter/twemoji), © Twitter, Inc. и
другие авторы, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
